# 《玛法战纪》PRD

> 文档状态:**草案 v1.5,待评审**
> 产品载体:FoloToy AI Passport / ESP32-C3 / 240 × 320 LCD / 三键(上/下/OK,ADC 分压)
> 目标分支:`feature/mafa-chronicle`
> PRD 版本:v1.5
> 更新日期:2026-09-30

---

## 1. 产品概述

### 1.1 产品名称

- 中文名(工作标题,可改):玛法战纪
- 英文 UI 名:`MAFA CHRONICLE`
- 内部特性名:`Mafa Chronicle`(文字传奇类单机 RPG)

### 1.2 定位

《玛法战纪》是运行在 FoloToy AI Passport 上的**单机文字挂机 RPG**(文字传奇类):玩家选择战士/法师/道士之一,选定地图后**角色自动战斗刷怪**,战斗过程以滚动日志呈现;玩家的操作发生在战斗之外——穿装备、卖装备、买药、切换更深的地图、迎接 Boss 事件——以**打怪 → 掉装 → 换装 → 挂更深图**的成长循环为核心体验。

画面保持经典文字传奇三段式,外加金色描边的面板装饰(v0.7):顶部信息带(地图名与 Boss 击杀进度、等级与升级经验百分比、金币、血条蓝条),敌人条(含怪物血条,Boss 战时名字变金),中部滚动战斗日志(游戏的"画面",描边面板加金色小标),底部动作栏。所有装饰控件每屏只创建一次、差量刷新,无逐 tick 分配。三键即全部输入。

### 1.3 核心价值

1. **每分钟都有数字在涨**:经验、金币、掉落、等级,成长反馈密度高。
2. **爆装惊喜**:品质分档(白/绿/蓝/紫/金)与掉落随机,让每一场战斗都可能开出好东西。
3. **三键可玩**:上下选、OK 确认、长按返回,零学习成本。
4. **短会话**:开机会即自动开刷,随时放下;解锁一张新图约 20~40 分钟,契合碎片时间。

### 1.4 与 FOG MARCH 的关系

- 本应用是**独立衍生应用**:有自己的 PRD、UI 与代码(`main/mafa_*.c`),不沿用战棋的画面壳;BSP、字体生成管线、LVGL 防抖刷新模式、"纯逻辑模型 + 宿主测试"架构直接复用。
- FOG MARCH P0 已达稳定可玩状态,保留在树中;`main.c` 入口切换到本应用。

## 2. 背景与设计输入

### 2.1 硬件事实

- ESP32-C3,8MB Flash,无 PSRAM;240 × 320 RGB565 屏;三 ADC 分压按键(上/下/OK);单声道扬声器;电池电量可读。
- LVGL 9.5 + esp_lvgl_port;内置 malloc 池现为 96KB(FOG MARCH 实测教训:池耗尽会让渲染任务持锁死循环,整机冻结)。
- 存在 NVS 分区;存在按码点清单生成 CJK 子集字体的工具管线。

### 2.2 设计输入

- FOG MARCH 真机试玩反馈(2026-09-28):操作可接受,但战棋玩法"没有乐趣"——决定缺乏分量、一局没有节奏弧线。玩家明确偏好**打怪刷装备的成长循环**。
- **对标参考**:TapTap 创意工坊《文字传奇》(app 842887,竖屏文字挂机传奇 RPG:自动战斗刷怪、装备掉落收集、商店购买、多地图探索,五大地图)。其玩家差评即本产品的硬性需求:
  1. "没有存档,每次进入都是新的开始" → 存档是一等公民,断电续玩是验收项;
  2. "攻防还得自己手动,操作非常差" → 战斗必须自动,玩家决策在战斗外;
  3. "要做的只有无限手动卖装备和点加血加蓝" → 自动卖白装、自动喝药是必备开关;
  4. "内容极度匮乏" → 内容量是生死线,P0 用三张扎实地图起步。
- 文字传奇品类的成熟结构:菜单驱动、数字成长、掉落惊喜;历史上原生运行于 9 键/3 键设备。

### 2.3 核心输入约束

全部交互 = 上 / 下 / OK(单击)+ OK 长按(返回)。任何界面必须能仅用这三个输入完成;不依赖长按达成唯一路径的关键操作(长按只是便捷返回)。

## 3. 关键假设与风险

### 3.1 最高优先级假设

**H1:成长循环本身能产生乐趣。** 验收方式见第 13 章 DoD:真机多会话试玩,玩家自发想"再来一局"。

### 3.2 次级假设

- H2:三键足以完成全部操作且不显笨重(动作菜单 ≤ 5 项、背包 ≤ 8 格,列表深度可控)。
- H3:16px 中文 + 血条/日志的排版在 240 × 320 上清晰可读。

### 3.3 已识别风险

- **内容量失控**:传奇类乐趣依赖内容量。对策:P0 边界(第 4.3 节)宁小勿大,先验证手感。
- **数值不平衡**:对策:M2 阶段写宿主侧模拟器,自动跑 ≥1000 场校验各级胜率曲线(玩家 vs 各区域怪物的胜率、预期场次数),表驱动调参。
- **LVGL 池压力**:文字页对象数远小于战棋地图,但仍沿用 diff 刷新模式并在真机复核。
- **字体清单遗漏**:沿用 FOG MARCH 的码点核对测试(tests/test_fog_ui_glyphs.py 模式),文案改动必须同步清单。

## 4. 目标与非目标

### 4.1 P0 目标

1. 一个可反复游玩的成长闭环:挂机刷怪 → 掉装 → 穿装/卖装 → 挂更深的图。
2. 三职业可选,各 **7 个自动施放技能,学习等级 1:1 采用原版 1.76 真实等级**(v1.4,见 8.4)。
3. **七张沿原版练级路线排布的地图**(v1.4,见 8.7):比奇省 → 兽人古墓 → 石墓 → 沃玛寺庙 → 死亡山谷 → 祖玛寺庙 → 赤月峡谷,共 27 个层 Boss 检查点;等级上限 40。
4. 装备为**原版 1.76 装备栏去掉蜡烛位与护身符位 —— 8 个位置、6 种部位**(武器/头盔/衣服/项链/手镯/戒指 ×2),五品质档,装备按**攻击/魔法/道术**三线带职业属性(圣战偏攻/法神偏魔/天尊偏道),掉落与商店双来源;自动卖、自动喝药默认开。
5. NVS 断电存档,自动存档点覆盖全部关键状态变更(对标本品最大差评)。

### 4.2 成功指标

- 真机 DoD 全绿(第 13 章)。
- 宿主模拟器(每层,建议等级 + 该层"到达装备" + 商店书 1~3 + 到达等级已解锁的后期书 + 30 红 30 蓝药 —— v1.7):
  - 战斗节奏 4~15 秒/场;
  - 建议等级挂机死亡间隔 ≥ 4.5 分钟(v1.7,原 5 —— 后期书按等级门槛掉落,终局刷怪合理变难);
  - **墙层**(每图末层):至少一个职业胜率落在 45%~75%,无职业 0%;
  - **走廊层**:各职业节奏与死亡门槛全部达标,外加"不许白给"(至少一个职业 ≤90%)。

### 4.3 P0 非目标

- 联网、多人、PvP、聊天;MMO 剧场(世界频道/假玩家/排行榜,见 14 章 P1)。
- 挂机/离线收益(挂机仅开机进行)、多存档位、装备强化与合成、转职、多技能树。
- 触屏、实时操作、地图编辑器、手动战斗模式。
- 大世界自由探索(线性地图解锁)。

## 5. 目标用户与场景

### 5.1 目标用户

持有设备的玩家本人;熟悉传奇类玩法语境;用碎片时间开机玩几局。

### 5.2 核心场景

1. **通勤五分钟**:开机 → 继续 → 看着挂机收几件装备 → 关机,进度已存。
2. **整块二十分钟**:切到最深的图挂机,接一次 Boss 事件,穿新装、买药、再挂。
3. **刷装时刻**:守在高级图反复触发 Boss,赌紫装/金装;世界没有别人的进度,自己的节奏自己定。

## 6. 核心循环

```text
主界面(选图挂机)
   │  角色自动砍怪:日志滚动,经验/金币/掉落持续入账
   │
   ├─ 战斗外操作:背包穿装/卖装 · 药店买药 · 切换更深的地图
   │
   ├─ 击杀累计触发 Boss 事件 ──▶ 胜利:解锁下一张图 + 紫金掉落
   │                              失败:无惩罚,继续挂机
   ▼
数字变强 ──▶ 挂更深的图 ──▶ 掉更好装备 ──▶(循环)
```

- **挂机是默认态**:开机进主界面即在当前地图自动战斗;玩家随时可以只看不动手。
- **Boss 事件**:每张图累计击杀 25 只怪触发一次("森林巨猿出现了!"),三键选择迎战/回避;击败后计数清零可再次触发(可反复 Farm)。Boss 掉落走紫/金 roll,是 Farm 的终极钩子。
- **推进感**:解锁新图 = 世界变大;新图怪物更强、掉落档位更高(见 9.2/9.3)。
- 双反馈嵌套:每场战斗的秒级日志(短)、Boss 事件的分钟级目标(中)、等级/解锁的长线成长(长)。

## 7. 信息架构(屏幕流)

```text
开机 ─▶ [继续 / 新游戏] (新游戏 → 选职业)
              │
              ▼
     ┌── 主界面:选图挂机(状态栏 + 战斗日志 + 动作菜单)──────────┐
     │   动作菜单(2×4,F16):背包 / 装备 / 技能 / 商店 /            │
     │                        地图 / 设置 / 加速(第 8 格留空)      │
     │        ├─ 背包(穿 / 卖 / 一键卖白)                           │
     │        ├─ 装备(8 槽纸娃娃 + 属性 + 药水)                     │
     │        ├─ 技能(7 个职业技能 + 状态 + 开关)                   │
     │        ├─ 商店(红蓝药 + 3 本等级门槛职业书)                  │
     │        ├─ 地图(安全区 + 7 张战斗图 → 选层列表)               │
     │        ├─ 设置(开关 + 喝药线 + 电量)                          │
     │        └─ 加速(1x / 2x / 4x)                                  │
     └─ Boss 事件弹窗(迎战 / 回避)◀── 击杀计数触发 ──────────────────┘
```

## 8. 功能需求

### 8.1 职业

三职业,开局选择,不可更改。属性含:HP / MP / 攻 / 魔 / 道 / 防 / 等级(v1.5:攻击/魔法/道术三线,技能与装备各走其线)。

| 职业 | 定位 | 输出风格 |
| --- | --- | --- |
| 战士 | 高 HP 高防,稳定输出 | 平砍扎实 + 攻杀触发/烈火蓄力,多怪时半月清场 |
| 法师 | 最高魔,脆皮 | 单体核弹 + 全体灼烧,魔法盾保命;清怪快、药钱多 |
| 道士 | 道术续航,持久战 | 宠物坦克 + 火符输出 + 奶/毒续航,挂最深的图不易死 |

### 8.2 属性与成长

- 经验只来自战斗;升级自动加点(无手动加点,P0 简化)。**等级上限 40(v1.4)** —— 覆盖全部 1.76 技能(最高解锁 35 级)并留几级满配体验。
- 升级所需经验采用**前快后墙曲线**,形状对标原版 1.76(新手期爽快、中期 ~×1.3 复利、满级前一道长墙)。39 档曲线(v1.4)按段概括:

| 区段 | 形状 | 备注 |
| --- | --- | --- |
| L1~7 | 近线性(100 → 1800) | 原版式新手快跑 |
| L8~20 | ×1.3 复利 | L20→21 = 92,000 |
| L21~30 | ×1.25 复利 | L30→31 = 610,000 |
| L31~38 | ×1.28 走陡 | L38→39 = 2,130,000 |
| L39→40 | **经验墙** | 12,000,000,约占全程(~2630 万)的 46% |

- **三线属性(v1.5)**:每个职业一条主属性线 —— 战士吃**攻击**、法师吃**魔法**、道士吃**道术**;技能(8.4)与装备属性线(8.5)都按这条线结算,对齐原版三职业属性体系。法师/道士的平砍保持低攻击(走武器),战士没有魔/道线。
- 每级成长(基础值 + 每级增量;法师 HP 自 v1.4 每级 +1;战士自 v1.5 带小蓝条,烈火/半月/野蛮消耗 MP):

| 职业 | HP | MP | 攻 | 魔 | 道 | 防 |
| --- | --- | --- | --- | --- | --- | --- |
| 战士 | 60 +8 | 10 +1 | 11 +2 | — | — | 5 +1 |
| 法师 | 40 +6 | 30 +5 | 10 +1 | 14 +2 | — | 3 +1(每 2 级) |
| 道士 | 60 +6 | 25 +4 | 10 +1 | — | 12 +1 | 4 +1 |

- MP 回复:每回合结束 +2(战斗中);脱战状态下 HP/MP 按 8.8 缓慢恢复。

### 8.3 战斗(自动)

- **战斗全自动**:进入地图后角色按 1.5 秒/回合自动砍怪(倍速 1x/2x/4x 可切),全程日志流呈现。
- **多怪战斗(v0.8)**:普通战斗按地图权重刷 **1~3 只怪**(越深的图越多:图1 ≈ 70/30/0,图2 ≈ 40/40/20,图3+ ≈ 20/40/40);怪物种类按玩家等级上限抽取——各职业第一个技能形态(火球术/基本剑术/治愈术,均为 7 级)之前上限贴身等级(1~6 级没有伤害技能,新号在比奇只会遇到鸡/鹿),7 级起恢复经典 +2 级带宽;整层怪都高于上限时回退全层池。玩家攻击第一只存活的怪,AoE 技能打全体,**每只存活的怪每回合都会行动**(被撞晕的怪跳过,见 8.4)。Boss 战保持 1v1。
- **普通攻击**:`伤害 = max(1, floor(攻 × U(0.9, 1.1)) − 防)`;U 为 0.9~1.1 的整数随机。
- **爆击**:10% 概率,攻击 ×1.5;日志"【爆击】"前缀。
- **技能全自动**:按 8.4 的优先级策略自动施放,日志以技能名开头。
- **自动喝药**(设置开关,默认开):HP 低于**红药线**自动红药、MP 低于**蓝药线**自动蓝药(v1.2:两条线可在设置页调整,20%~80%、步进 10%,默认 50% / 30%)。药水按等级小幅放量的固定回复(见 8.8),任何阶段"一瓶药约等于挨一下"。
- **死亡**:HP ≤ 0 → 日志"你被 xx 杀死了…" → 在安全区满血满蓝复活,玩家自己选图再出发,死亡惩罚见 8.9。
- **战斗日志**:滚动显示最近 6 条。击杀/掉落/升级/Boss 事件用强调色;怪物包显示为"▶多钩猫×3"配聚合血条,宠物通过日志播报。
- 怪物 AI(P0):普攻;HP < 30% 时 50% 概率使用怪物技能(见 9.2 表)。
- **自动卖(v1.2,取代自动卖白)**:可**多选的品质集合**,命中集合的掉落即按定价折算金币入账,不占背包;其余进背包等玩家处理。可选:白 / 绿 / 蓝 / 紫 —— 各占 1 位,默认**只卖白**(即旧行为)。**金永不自动卖**:传说掉落必须交到玩家手上。设置行汇总当前集合(「自动卖:白绿」);OK 打开就地选色器,四个颜色按品质色显示,另有一个完成行(设计稿 15)。

### 8.4 技能

- **每职业 7 个,学习等级 1:1 采用原版 1.76 真实等级(v1.4)** —— 下表等级为社区多源核实的一致值;逐日剑法为唯一 1.80+ 技能(用户批准的例外)。解锁条件为**等级 + 技能书**(见 8.5):每职业第 0 个技能免书,第 1~3 个为商店书,第 4~6 个只掉落。解锁后全自动施放。
- **技能按属性线结算(v1.5)**:战士技能吃攻击,法师技能吃魔法,道士的 火符/毒/治愈/召唤兽 吃道术(治愈 = 25% 最大 HP + 道术;毒量 = 5 + 道术/5 每回合;宠物属性随等级与道术成长)。**战士自 v1.5 带小蓝条**(原版战士有蓝条且主动剑术耗蓝,社区口径 烈火 ≈8/半月 ≈5/野蛮 ≈3):法师/道士为 MP 制,战士为 MP+冷却双门。新增两个形态(v1.4):**眩晕**(野蛮冲撞 —— 伤害且目标跳过下一回合)与**加防**(神圣战甲术 —— 防御 +40% 持续 4 回合)。
- **技能状态常驻可见于技能页(v1.4)** —— 纸娃娃扩到 8 槽后技能独立成页(动作菜单「技能」格):列出本职业全部 7 个技能的实时状态 —— "常驻"(被动/触发)、"开/关"(主动技,OK 切换并立即存档)、"书店N金"(可购买)、或锁定原因 "Lv35" / "精英/Boss"(先看等级门槛,再看书的来源;第 0 技能免书,锁定行显示「Lv X 自动习得」)。**v1.7 起掉落的书不会再先于解锁等级到手**,等待状态就是"等级已到、书未掉落"—— 技能页以"精英/Boss"锁定提示呈现。
- **主动技能可关闭(v1.2)**:技能行按 OK 切换开/关(被动/触发行固定);自动施放策略跳过已关闭的技能。把主动技能全关 = 纯普攻挂机,是合法玩法而非错误状态。**固定/未习得行按 OK 不再静默(v1.4)**:底部说明栏临时显示原因 —— 「等级不足,需 Lv X」/「书店购买后习得」/「精英/Boss掉落习得」/「被动技能常驻生效,无开关」,移动光标或重进页面即恢复说明。

**Boss 战规则**(平衡模拟器校准结论,PRD 4.2):

### 8.5 物品与装备

- **纸娃娃(v1.4)**:原版 1.76 装备栏去掉蜡烛位与护身符位 —— **8 个位置、6 种部位**:武器 / 头盔 / 衣服 / 项链 / **双镯** / **双戒**。镯/戒装备时**优先落空位**,双位皆满才替换左位(换下的回背包)。

### 8.6 掉落

每击杀一只怪结算 roll 一次(见 9.3 表):

- 金币:怪物等级 × U(2,5) —— 中后期一只怪的赏金约等于一瓶药。
- **技能书(v1.7)**:只从精英与 Boss 掉,且只掉已到解锁级的书 —— 每次击杀对"下一个缺失且已够级"的书掷一次:Boss **30% / 15% / 8%**(书 4/5/6),精英 **5%**。掉落即当场习得(不占背包)。
- **药水(v1.5)**:小怪 **15%** 概率掉 金创药/魔法药(红 60% / 蓝 40%),直接入计数器(不占背包,上限 99),日志「获得 金创药」;商店仍是补给主渠道(目标:掉落覆盖约 1/3 消耗)。

### 8.9 死亡与安全区

HP ≤ 0:日志"你被 xx 杀死了…" → 在**安全区**满血满蓝复活(v0.9),挂机暂停,直到玩家在地图页自选下一张图 —— 被踢回城本身就是死亡代价的一部分。Boss 击杀计数清零,并按原版白名 PvE 规则结算惩罚(v0.8):

- **背包**:随机失去 1~2 格物品(整格消失,放置游戏不做跑尸);
- **金币**:损失携带量的 10~20%;
- **身上装备不掉**(单机放置游戏太伤,药水也不掉)。

安全区(v0.9)是地图 id 0,置于地图页首行(v1.0):始终可进,无怪无 Boss;战斗图仍按 8.7 由上一张图的末层 Boss 解锁(v1.3 分层)。**进入安全区即回满血蓝(v1.4)** —— 死亡复活与主动回城一视同仁,城镇成为真正的休整点;日志以「血蓝已回满」回应。

## 11. 文案与字体

## 12. 内存与 Flash 预算

- LVGL 池:文字屏对象 ≤ 40 个/屏,沿用 diff 刷新与按需创建;池维持 96KB 不再上调。
- Flash:字体子集 ≈ 100KB;怪物立绘(可选,小图)+ 装备图标 ≈ 50KB;代码与表 ≈ 100KB。8MB 内充裕。
- 任务栈:沿用 fog 的 input task 4KB 配置;战斗逻辑不递归。
